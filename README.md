# 手机开发商 · Mobile Manufacturer

把《手机开发商设计方案》（GDD）里的核心系统做成一个**能真正玩的浏览器原型**：从年代科技树起步，亲手设计手机（2D 六视图 + 3D 模型同源联动），排产、定价、进入全球 12 个市场，和**十六家**按史实入场、衰退、退出的 AI 竞争对手抢份额。

纯前端，无构建步骤，原生 ES Module + three.js（已本地化到 `vendor/`）。当前版本 **1.12.0**。

## 运行

```bash
npm start            # 启动本地服务器 http://127.0.0.1:8124
```

或任意静态服务器指向本目录（必须用 http 协议，ES Module 不支持 file://）。

```bash
python3 -m http.server 8124
```

PWA：`manifest.json` + Service Worker（`sw.js`，发版时 `CACHE` 尾号 +1 强制刷新），可安装到桌面离线游玩。APK 壳见 `HANDOVER.md`。

## 玩法主线

1. **选年代开局**：1980 / 1990 / 2000 / 2010 / 2020 / 2035，起步公司掌握的是三四年前的成熟技术（`ERAS.lag`），留出一条可以追赶的研发队列。
2. **选手机模板**：直板按键机（1980）→ 触摸屏+按键（2004）→ 触摸屏+功能键（2007）→ 全面屏（2017）。模板决定可用板块：屏幕比例/尺寸上限、开孔、键盘、Home 键、折叠、附加功能；切换时整机参数自动适配到该世代预设。
3. **设计手机**：机身长宽厚、边框、屏幕、键盘（T9/QWERTY、网格/全贴合、键宽键高/导航簇独立可调）、处理器/内存/存储/电池、逐颗摄像头（类型年代锁、大小/厚度/位置/Deco 布局）、材质配色、背面装饰、折叠形态。左侧分区折叠调参，中间 2D 六视图与 3D 模型实时同步，右侧给外观评分、BOM 成本、内部空间与装配检查（空间不足 / 摄像头凸起 / 折叠未成熟都会拦下量产）。
4. **屏幕 UI 设计**：独立设计页做壁纸导入、状态栏、导航键、Dock、桌面网格，并可单独设计**锁屏画面**（壁纸/时间/日期/通知/上滑解锁）；导航键与手势条会自动为 Dock 让出空间，三大键可翻转方向，手势条长度/粗细与电池纵向位置均可调。编辑使用草稿副本，**保存/完成**才写入存档，可**不保存退出**；保存后在设计器屏幕区选用。
5. **量产与排产**：委托代工或自建工厂，设定月产量与质量投入；产能、现金、良率与**元器件库存**共同决定产出。可一键「智能匹配排产」（按上月销量×热度−半库存）。
6. **供应链采购**：六大类元器件各有交期与多家供应商（可查板/比价），先下单再生产；库存不足按 **+16% 现货溢价**急采；供应商会出断供事件。
7. **建园区**：6 块地块、6 类楼宇（总部/研发/生产/设计/物流/品质）、最高 5 级，施工倒计时；**3D 园区可直接编辑**（房间拖放/改尺寸/放家具/加隔墙/开门），另有 **2D 平面规划页**双端同源。
8. **定价与渠道**：12 个市场单独定价，需求由产品力、品牌、价格弹性、渠道关系与产品热度共同决定；`¥80 万`进入新市场。**量产不等于发布**：新机型必须办发布会才开始销售，一场发布会可同时发布多款（基础 ¥500 万，每多 1 款 +¥150 万；一机只能发布一次），流程为**叙事风格 → 定价猜谜 → 卖点选择 → 记者问答 → 现场评分**，发布会后生成科技圈舆论。**所有弹窗打开时自动暂停时间**，关闭后恢复原速度。
9. **产品线与系列**：5 条产品线（旗舰/中端/低端/商务/电竞），系列自由命名；同期**存储配置**（12+256/12+512…，各自定价）与**同系列新机型**（Pro/Pro Max/Ultra，用「复制为新机型」派生后改尺寸规格）；产品页按**待发布 / 在售 / 已退市 / 设计中**筛选，有待发布机型时顶部给出「去发布」快捷入口。
10. **带团队**：10 个职能部门，招聘（社招/校招+招聘会/猎头）、加薪、解雇、调部门、4 类培训；能力定职级（初级→专家），可任命部门主管与高管；明星员工有品牌加成也会被挖角；**员工档案**显示能力画像、月流失风险与成长，竞品财报里可**猎头挖角**。
11. **自研部门**：半导体/光学/系统/面板四部门，等级 1–5，多款产品并行研发（设计→研发时间线→完工入产品池），自研部件可用于自家机型或对外供货；部门等级还会给**子品牌技术共享**（利润加成）。
12. **系统科技树**：系统开发部专属 5 分支 15 节点（流畅/智能/隐私/互联/发行），另有三代系统路线（轻量内核→全场景 OS→AI 原生，加成叠加）；自研 OS 生态有流行度、版本命名、**第三方厂商授权（最多 5 家）与应用商店 15% 分成**。
13. **发布会与拆解**：发布会进入 3D 舞台（追光、观众、背景屏）+ 叙事风格/定价/卖点/记者问答 mini-game；设计器可切「拆解视图」逐层展开内部结构。
14. **经营与研发**：6 大类 **68 个科技节点**（通信/处理器/屏幕/影像/电池/系统与其他），按年代与前置依赖解锁；可直接**技术引进**购买对手成熟技术；零件/传感器年代是**硬锁**，未来技术无法偷跑量产。
15. **资本运作**：多轮股权融资、IPO 上市、收购谈判（对手会还价）；支持**现金 / 分期 12 期 / 换股**三种支付、**公关游说**降低反收购防御、**敌意收购**（溢价 35%，可能被董事会拒绝）；成交后有 6~9 个月**整合期**（利润打折、品牌摩擦，期满释放协同）；子公司会自主/手动发品、转让技术、推荐人才。
16. **竞争市场**：16 家对手各有**招牌能力**（耐用续航/面板自产/生态闭环/商务安全/影像旗舰/极致性价比/轻薄设计/性能极客），会**产能不足缺货**、互相**并购与结盟**（联盟 +6% 曝光），每家都有**财报页**（现金/营收/品牌/份额/产能/12 月销量）。
17. **七个里程碑**：首款上市 → 10 万台 → 全球 1% → 自建工厂 → 5 个市场 → 年营收 10 亿 → 全球 5%。
18. **全球门店**：每个市场最多 3 家门店（标准店/旗舰店/地标店），开店与升级提升本地曝光/客流/转化；每月维护费，关店回收 30% 累计投入。
19. **区域营销 2.0**：在全局渠道预算之外，按机型 × 市场 × 活动类型（社交种草/线下广告/电竞赛事/运营商捆绑/媒体评测）投放；营销趋势每 6 个月轮换，匹配趋势/产品定位/市场部人力时效果更高。
20. **OS 主题商店**：屏幕设计保存的方案可直接设为 OS 主题，主题评分影响 OS 流行度、授权收入与主题商店收入；OS 生态从“科技树”变成可运营的视觉产品。
21. **五轨 Perk**：管理 / 经济与基础设施 / 生产与技术 / 市场与受众 / 影响力与支配五条成长轨；经营行为积累 XP，升级二选一、永久生效，不加创始人背景。
22. **银行贷款 2.0**：信用分、额度、3 档期限与利率、随时部分/全额还款、到期日与逾期罚息；信用与经营状况影响后续借款条件。
23. **设备形态**：手机 / 平板 / 智能手表（圆表、方表）共用设计器；平板复用大屏机身与 2D/3D 渲染，手表只做表体与圆形/方形屏幕，不做表带。
24. **包装设计**：盒型材质（环保纸盒/硬质塑料/高端礼盒/极简无塑）、主色、Logo、盒面文字与即时预览；影响单机包装成本与开箱评价。
25. **OS 实机预览**：主题预览支持手机/平板/圆表/方表形态切换，桌面/锁屏、横竖比例与圆角实时变化。

沙盒模式：自定义资金/年代/科技解锁，并可开「研究瞬间完成」「建设瞬间完成」。

### 年代基准与经济校准

从 1980 玩到 2035，绝对分值会失效：1980 年的顶级手机性能只有 2 分，拿固定的 50 分做参照会判成垃圾；2020 年的主流机性能 84 分，同一把尺子又全员优秀。

- `eraBaseline(year)`：用该年代全部可得科技造一台主流机，它是那个年代的「50 分」。
- `eraRel(value, base)`：把任意指标换算成同代倍率，1.0 = 与主流机持平，1.5 = 明显更强。
- `eraCostScale(year)`：把主流机 BOM 锚定到零售价的 52%，让 1980 的 63 倍加价与 2020 的 0.7 倍加价统一成 1.92 倍。

没有这三条，早期年代是印钞机、晚期年代卖一台亏一台；现在是同一条难度曲线。

## 与 GDD 的差距

- **园区 3D 地块/楼宇实体**：楼层内部已可完整编辑（房间/家具/隔墙），但园区层面的地块与楼宇仍是 2D 卡片，尚未把整片园区画进 3D 场景。
- **生产线工艺差异**：有代工/自建工厂、质量投入与自动化产线维护，但没有 GDD 里的工艺路线选择与自研设备。
- **折叠机 3D 相机**：折叠机展开态的 3D 取景未按展开足迹适配（相机偏近），2D 蓝图正常。
- **按键机 3D 键面字符**：2D 键面有数字/字母丝印，3D 键帽仍是纯色块。
- **曲面屏**：按需求主动搁置，未实现。
- **技术路线深化**：通用科技树仍是线性解锁（系统线已有三代路线），光学/面板品类尚无互斥分支。
