# 园区办公室系统重做（v0.8.0）——3D 编辑 + 2D 平面规划双端

## Context（为什么做）
现系统三处结构性缺陷（探查已确证）：
1. **房间穿墙**：9 个部门房间位置硬编码在 `office.js deptCenter()`（北 5 南 4、24×24），北排 5×24=120 超过楼体外壳 104，端部房间连同工位/灯带整体越出外墙 8 个单位；全链路零碰撞校验。
2. **家具重叠**：自动工位（按人数即时生成的裸 mesh，最多 12 个，不入数据）与用户家具（officeLayout.items）是两套体系，互不知晓，必然穿插。
3. **编辑器难用**：openLayoutModal 是 13×13 HTML 弹窗，点一下销毁重建整个 3D 场景+整页 DOM；无拖拽/旋转/撤销/实时预览；隔墙不参与寻路（纯装饰）；放置只查同格重复。

目标：房间位置与尺寸可在 **3D 内**与 **2D 平面规划页**两处手动布置（拖放+红绿校验，双端数据实时一致）、家具单一数据源且互不重叠、编辑不重建场景、寻路感知墙与门。参考 Two Point Hospital（拖拽画房+校验+模板）、Prison Architect（周界围合校验）、Mad Games Tycoon 2（桌子=工位、员工分配房间）、通用建造 UX（幽灵预览+逐格红绿）。

## 核心设计：单一网格 + 共享校验层（双端同源）
- **一张楼层网格**：`CELL=4` 世界单位，楼层 `FLOOR_W=30 × FLOOR_H=20` 格（120×80 世界单位）。房间、家具、隔墙、门、寻路同一坐标系。
- **共享逻辑层 `js/core/floorplan.js`（新，纯逻辑、Node 可测）**：占用图构建、房间移动/调尺寸校验（越界/重叠/大门可达 BFS）、家具放置/移动校验（含与内置工位互斥）、门自动指派、楼层 BFS 与房内 BFS（隔墙=边阻挡）、v1→v2 迁移。**3D 编辑器与 2D 规划页只做渲染与拾取，校验一律调这一层——双端行为永远一致**。
- **房间模型（可调尺寸）**：`officeLayout.rooms[deptId] = {cx, cy, w, h}`（w/h ∈ 3~8 格，默认 6×6=24×24）；外围自动墙（相邻房间共享墙线只画一次）+ 部门色发光沿 + 自动选门（用户可点墙改门位）。
- **家具单一数据源**：`items` 增 `rot/uid/builtin`；自动工位改为随人数自动增减的内置 desk items（免费、自动落位空闲格），用户 desk 同权计容量；`officeCapacity` = 房间内 desk 总数 + 基础。
- **寻路感知**：员工跨房走楼层 BFS、房内走房内 BFS（隔墙挡路），`planExit` 从当前位置出发；校验保证每房至少一门连通大门，不会困死员工。
- **迁移**：v1→v2（rooms 默认双排布局全落楼内、走廊带 3 格、入口区南中 4×2 不可建；items 索引原样保留，家具随房走）。

## 编辑端一：3D 内直接编辑（office.js）
- 「室内编辑」进入编辑模式：相机抬升、网格线浮现、悬浮工具条（部门 chips + 工具：家具×6/隔墙/门/移动房间/调尺寸/拆除/完成）。
- 幽灵预览跟随 raycast、逐格红绿、R 旋转、点击放置；点选房间→整房幽灵（家具随房）拖放；四边手柄调尺寸（缩小自动回收界外家具并 toast）；点家具选中→拖拽移动/R 旋转/卖出 50%，**移动免费**。
- 全部操作走 **增量更新 API `updateLayout()`**（只重建家具组/墙组/门牌/容量标签，人员不动）+ autoSave；移除「放一件家具重建整个场景」。

## 编辑端二：2D 平面规划页（新 `js/ui/floorplan2d.js`）
- HQ 页新增「平面规划」按钮 → 全屏俯视规划页（canvas 顶视图，整层楼尽收眼底，适合精确规划；3D 编辑适合沉浸摆放）。
- 绘制：楼层网格 + 房间色块（部门色描边+名称+人数）+ 家具小图形（按 rot）+ 隔墙/门 + 入口区 + 选中/幽灵态；自动 fit 缩放。
- 交互与 3D 编辑同构：同一套工具条、同一套 floorplan.js 校验、幽灵红绿、拖拽房间/家具、R 旋转、点击放置；canvas pointer 事件 + 命中检测（坐标换算与绘制同源，沿用约定 19 的思路）。
- **双端同步**：任一端接受的操作写同一份 `state.officeLayout` → autoSave → 若 3D 场景在挂载中则 `updateLayout()`；从 2D 关闭回到 HQ 立即看到 3D 结果。
- 顶部显示实时数据：各部门工位容量/满意度加成/研发加成 + 校验提示（哪间房不可达等）。

1. **`js/core/floorplan.js`（新）**：如上共享逻辑层。
